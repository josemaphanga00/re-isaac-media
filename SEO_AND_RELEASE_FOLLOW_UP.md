## SEO improvements to do next

### High priority

- [ ] Use Google Search Console to check indexing, sitemap processing, canonical selection, mobile usability, and search queries. Record actual data before making ranking claims.
- [ ] Improve gallery and portfolio image `alt` text where it describes meaningful content. Replace repeated generic text such as “Photography by Isaac Media” with concise, accurate descriptions; keep decorative images' alt text empty.
- [ ] Review title and description wording against the services and locations that are genuinely important (for example, wedding photography, videography, Pretoria, and South Africa). Keep copy natural and non-repetitive.
- [ ] Confirm structured data matches the visible business details: name, contact information, service area, address, pricing, and social links. Validate JSON-LD with Google's Rich Results Test or Schema Markup Validator.

### Medium priority

- [ ] Confirm the Open Graph and Twitter/X image is publicly accessible, has suitable dimensions, and renders in link-preview debuggers for WhatsApp, Facebook, and LinkedIn.
- [ ] Review internal links and navigation for useful, crawlable destinations. Modal content is generated by JavaScript and query-string URLs are not separate static pages; decide whether key services/packages merit indexable standalone landing pages.
- [ ] Check that the canonical host is consistently `https://www.isaacmedia.co.za/` and that HTTP, non-`www`, and duplicate URL variants redirect to it.
- [ ] Keep sitemap entries limited to canonical, indexable URLs. Update `lastmod` only when the page content meaningfully changes.

### Ongoing

- [ ] Monitor Search Console impressions, clicks, queries, indexing, and Core Web Vitals after launch.
- [ ] Capture repeatable Lighthouse mobile and desktop runs on the production URL; record Performance, Accessibility, Best Practices, SEO, LCP, CLS, and INP/TBT without treating a single run as definitive.
- [ ] Review local business listings and citations for consistent business name, phone, location, service area, and website.
